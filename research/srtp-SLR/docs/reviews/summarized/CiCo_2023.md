# CiCo: Domain-Aware Sign Language Retrieval via Cross-Lingual Contrastive Learning

## Basic Information
- Publisher/Date/Title: 2023, CiCo: Domain-Aware Sign Language Retrieval via Cross-Lingual Contrastive Learning
- Authors & Affiliations: Yiting Cheng¹, Fangyun Wei², Jianmin Bao², Dong Chen², Wenqiang Zhang¹
  (¹School of Computer Science, Fudan University, ²Microsoft Research Asia)

## Contributions & Features
1. Novel formulation of sign language retrieval as a cross-lingual retrieval problem
2. Development of domain-aware contrastive learning framework
3. Dual consideration of linguistic properties in both sign and natural languages

## Task
Develop a system for bidirectional sign language retrieval:
- Text-to-sign-video (T2V) retrieval
- Sign-video-to-text (V2T) retrieval

## Challenges
1. Dual Nature of Sign Videos:
   - Contains visual signals
   - Carries semantic meanings as natural language
2. Cross-Lingual Mapping:
   - Need to identify fine-grained sign-to-word mappings
   - Handle different linguistic structures
3. Domain-Specific Interpretation:
   - Consider context and domain-specific meanings
   - Balance between visual and semantic features

## Methods
1. Cross-Lingual Contrastive Learning:
   - Joint learning of visual and linguistic features
   - Fine-grained alignment between signs and words
2. Domain-Aware Framework:
   - Specialized handling of domain-specific content
   - Integration of contextual information
