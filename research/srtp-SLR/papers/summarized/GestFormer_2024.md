# GestFormer: Multiscale Wavelet Pooling Transformer for Dynamic Hand Gesture Recognition

## Basic Information
- Publisher/Date/Title: 2024, GestFormer: Multiscale Wavelet Pooling Transformer Network for Dynamic Hand Gesture Recognition
- Authors & Affiliations: Mallika Garg, Debashis Ghosh, Pyari Mohan Pradhan (Department of Electronics and Communication Engineering, Indian Institute of Technology, Roorkee, India)

## Contributions & Features
1. Novel resource-efficient transformer architecture for gesture recognition
2. Pooling-based token mixer (PoolFormer) instead of quadratic attention
3. Integration of wavelet transform for space-invariant features
4. Multi-scale pooling for feature selection

## Task
Develop a computationally efficient transformer-based architecture for dynamic hand gesture recognition

## Challenges
1. Computational Efficiency:
   - Traditional transformers are computationally expensive
   - Complex architectures with high resource requirements
2. Feature Extraction:
   - Need for space-invariant features
   - Multi-scale feature representation
3. Token Mixing:
   - Efficient alternatives to quadratic attention
   - Maintaining model performance with simpler components

## Methods
1. PoolFormer Architecture:
   - Non-parametric pooling layers
   - Replacement of traditional attention mechanisms
2. Wavelet Transform:
   - Extraction of space-invariant features
   - Multi-resolution analysis
3. Multi-scale Pooling:
   - Feature selection at different scales
   - Efficient token mixing strategy
