# Isolated Sign Language Recognition based on Tree Structure Skeleton Images

## Basic Information
- Publisher/Date/Title: 2023, Isolated Sign Language Recognition based on Tree Structure Skeleton Images
- Authors & Affiliations: 
  - David Laines*, Miguel Gonzalez-Mendoza, Gilberto Ochoa-Ruiz* (Tecnologico de Monterrey)
  - Gissella Bejarano (Universidad Peruana Cayetano Heredia)

## Contributions & Features
1. Novel use of Tree Structure Skeleton Images (TSSI) for sign language recognition
2. Spatio-temporal skeleton representation approach
3. Robust recognition across diverse conditions

## Task
Develop an embedded SLR system for video stream platforms using skeleton-based recognition instead of RGB information

## Challenges
1. Environmental Robustness:
   - Diverse backgrounds
   - Varying lighting conditions
   - Different physical appearances
2. System Integration:
   - Embedding in video platforms
   - Real-time processing requirements
3. Feature Representation:
   - Converting pose sequences to effective representations
   - Maintaining spatial-temporal relationships

## Methods
1. Pose Estimation:
   - Skeleton sequence extraction from videos
   - Advanced pose estimation models
2. TSSI Representation:
   - Tree structure for skeleton data
   - Spatio-temporal encoding
3. Recognition System:
   - Camera-based sign detection
   - Real-time processing pipeline
