# An Expert System for Indian Sign Language Recognition Using Spatial Attention

## Basic Information
- Publisher/Date/Title: 2024, An Expert System for Indian Sign Language Recognition Using Spatial Attention-based Feature and Temporal Feature
- Authors & Affiliations: Soumen Das, Saroj Kr. Biswas, Biswajit Purkayastha (National Institute of Technology Silchar, India)

## Contributions & Features
1. Novel Spatial Attention-based Sign Language Recognition Module (SASLRM)
2. Focus on Region of Interest (ROI) using attention mechanisms
3. Integration of pretrained VGG-19 features with spatial attention

## Task
Develop an expert system for recognizing Indian Sign Language words, particularly for emergency situations

## Challenges
1. Communication Barrier:
   - Limited understanding of sign language by general population
   - Need for automated recognition systems
2. Feature Extraction:
   - Previous systems focus on global features rather than ROI
   - Need for better local feature extraction
3. Attention Implementation:
   - Limited use of attention mechanisms in existing SLRS
   - Need for spatial attention integration

## Methods
1. Model Architecture:
   - Pretrained VGG-19 for feature extraction
   - Spatial Attention module
   - Combined convolution and attention features
2. Attention Mechanism:
   - Focus on hand regions
   - Emphasis on local feature extraction
   - Spatial attention implementation

## Data
1. Primary Dataset:
   - Indian Sign Language dataset
   - Focus on emergency situation words
2. Validation Datasets:
   - LSA64
   - WLASL
   - Cambridge Hand Gesture Recognition

## Evaluation
1. Performance Metrics:
   - ISL dataset: 95.627% accuracy
   - LSA64: 97.84% accuracy
   - WLASL: 98.86% accuracy
   - Cambridge Hand Gesture: 98.22% accuracy
